# 演示媒体与加载预算

演示动态保留实验室日常的幽默，也展示研究进度。28 条内置动态各自对应一张科研图示，其中光子计算周报还可以播放已有的 30 秒概念视频。

## 内容与来源

配图涵盖光学网络、机器人稳定性、凝胶交联、量子控制、数据泄漏、代码复现、缓冲液稀释和访谈编码等。日常向的动态也搭配相关的协作协议、检查点或记录流程。每张图及其页面说明都标识演示；曲线、状态和示例数据均为虚构，不代表实验验证。

图的英文标注用于示意研究结构，图片下方提供中文进度说明和下一步。每张图还有完整的中文替代文本，方便辅助阅读。

人物头像和横版 Logo 由 GPT-Image 生成，分别记录在[头像提示词](demo-avatar-prompts.md)和[品牌提示词](brand-prompts.md)。科研图示由本地 SVG 制图脚本绘制，再导出为 WebP；不使用外部图片服务，也不携带真实研究数据。

## 静态文件

## 修改与再生成

1. 在 `client/src/demo-figures.json` 修改对应帖子 ID、图名、中文说明和替代文本。
2. 在 `scripts/generate-demo-figures.mjs` 修改相应的图形函数。不要把虚构图示当成事实素材用于真实科研。
3. 在项目根目录运行 `npm run demo:figures`，将生成的 WebP 与代码一起发布。
4. 检查 `output/demo-figures/contact-sheet.png` 总览以及实际手机界面。脚本会拒绝重复 ID、缺失的图形和超过 55 KB 的单张图片。

生成文件位于 `client/public/demo/figures/`。调试 SVG 和总览图位于被 Git 忽略的 `output/`，不会打包到公共站点。

演示 API 在读取内置帖子时按 ID 补齐配图，所以已有浏览器中的点赞、评论、收藏、订阅和礼物记录无需重置。旧的乔南默认头像会更新为新图，自定义上传头像保持原样。这些配图只注入演示内容，不会自动添加到实验室服务器上的真实帖子。
