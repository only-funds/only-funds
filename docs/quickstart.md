# 五分钟开始

## 先体验一下

打开已部署的客户端，即可进入标有**演示空间**的本机环境。演示内容中的账号、互动与研究都是示例，不是实际实验结果。

- 在“研究动态”点赞、收藏、打开视频或发表评论。
- 在“发现创作者”订阅感兴趣的方向。
- 在“个人主页 → 设置 → 本机演示”切换**老板 / 创作者**身份。
- “还原演示”只重置本机示例，不影响任何实验室服务器。

## 加入真正的实验室

1. 向管理员取得**服务器地址**和对应身份的**邀请码**。
2. 打开 **Profile / 个人主页 → Settings / 设置**。
3. 输入 `https://serve.mylab.org`，点击**验证并连接**。也可输入带端口的 IP 或域名，省略协议时默认 HTTPS。
4. 回到“研究动态”，选择“加入实验室”。填写姓名、邮箱、至少 10 个字符的密码和邀请码。
5. 学生邀请码注册为**创作者**；老板邀请码注册为**老板**。注册页不能自行升级权限。

```{note}
GitHub Pages 客户端使用 HTTPS，远程实验室服务器也必须使用 HTTPS。普通 HTTP IP 不能直接从 HTTPS 网站通过 fetch 连接。管理员可通过项目自带的 Caddy 自动配置证书，详见部署指南。
```

## 你的第一条研究

学生进入“创作中心”，选择**研究手记 / 视频周报 / 论文笔记**，填写标题、正文、标签和来源后发布。视频支持 MP4 / WebM，最大 100 MB。

老板打开学生的动态，在评论里提出下一步方向；点击**打赏灵感**，送出一杯咖啡或一张组会免战牌。之后到“灵感奖励”中确认兑现。

## 在本机运行源码

需要 Node.js 24 或更新版本；创作者笔记工具需要 Python 3。

```bash
npm ci
npm run setup
npm run dev
```

- 客户端：`http://127.0.0.1:5173`
- API：`http://127.0.0.1:8787`
- `server/.env` 包含随机生成的邀请码与服务器密钥。此文件保存在本机，不应提交。
- 本地开发时可以在设置里填 `http://127.0.0.1:8787`，因为客户端本身也是 HTTP。

`npm run dev` 同时启动两个进程。客户端支持热更新；修改服务端后停止并重新运行命令。
