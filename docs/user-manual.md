# 日常使用

## 研究动态与订阅

“全部动态”显示本实验室按发布时间倒序排列的内容；“我的订阅”仅显示已关注创作者的内容。订阅对同一实验室的所有账号开放，没有付款或付费墙。

使用搜索框查找标题、正文或标签。每次读取最多 30 条动态；有更多结果时使用“加载更多动态”。研究详情中的来源链接在新页面打开。

## 点赞、收藏与评论

点赞是一句轻轻的“这很棒”。收藏是仅当前账号可见的列表，适合留存值得复读的论文笔记。所有实验室成员均可评论；老板评论会显示 PI 标记。

动态上的数字是点赞数和评论数，不是播放次数。当前 API 每条动态展示最早 100 条评论，适用于小组交流；大量讨论的分页尚未提供。

## 个人主页与设置

点击创作者头像查看其研究。自己的主页可以编辑姓名、研究方向与简介，并进入设置管理服务器和发布密钥。手机上也可以从个人主页进入“灵感奖励”。

服务器地址存在浏览器 `localStorage`；登录令牌存在 `sessionStorage`，在当前标签页会话有效。重新打开浏览器可能需要登录；账号和研究仍保存在服务器。退出登录会撤销当前服务器会话。

切换服务器会清除当前登录状态。不同实验室不共享账号，不自动迁移研究内容。

## 奖励的正确打开方式

| 奖励 | 承诺 |
| --- | --- |
| ☕ 续命咖啡 | 一杯星巴克或组里喜欢的咖啡 |
| ⚡ Token 自由 | $100 OpenAI API 额度，由老板报销或另行发放 |
| 🏝️ 组会免战牌 | 一次不做 slides 的快乐 |
| 🖥️ GPU 包夜 | 24 小时专用算力时段 |
| 📝 极速改稿券 | 48 小时内反馈论文草稿 |
| 🧋 全糖快乐 | 一杯奶茶 |
| 😴 睡到自然醒 | 一个没有早会的上午 |
| 🍜 深夜食堂 | 一顿让胃有着落的饭 |

老板在动态下选择奖励、写一句鼓励并送出。初始状态为**待兑现**；实际履行后，由发放者点击**确认兑现**。学生可以查看自己收到的记录。

```{important}
点击奖励不会扣款、发放 API key、购买星巴克或调整日历。OnlyFunds 记录承诺和兑现状态；实际奖励由实验室成员完成。奖励不替代薪酬或 stipend。
```

## 本机草稿与删除

创作者输入的草稿自动按“服务器 + 账号”保存在当前浏览器，避免切换实验室后混用。私有设备之外不建议保留敏感研究草稿。

创作者可通过自己动态右上角菜单删除动态。正文、评论和相关点赞收藏会删除；已有奖励记录保留。已上传的媒体文件不会自动清理，管理员须根据运维指南处理。

## 身份、计划和账本

在个人主页的设置中管理身份、年级、头像和订阅计划；“我的收入 / 我的账单”记录订阅期次、礼物使用和兑现时间。详细步骤见[订阅、收入与礼物账本](subscriptions-and-ledger.md)。
