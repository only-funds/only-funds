# 常见问题

## 网站打开了，但连不上实验室

先检查设置中的地址是否是 API 主机，而不是静态网站地址。浏览器访问 `https://serve.mylab.org/api/health` 应显示 OnlyFunds JSON。

| 现象 | 检查 |
| --- | --- |
| HTTPS 网站连接 HTTP 服务器 | 浏览器混合内容限制；给服务器配置 HTTPS |
| curl 正常，浏览器失败 | 将客户端准确 Origin 加入 `ALLOWED_ORIGINS` |
| 证书错误 | 检查域名解析、证书信任、80/443 可达性 |
| 内网 IP 在组外不可达 | 连接实验室 VPN 或使用可达的 HTTPS 入口 |
| 公司/校园浏览器提示本地网络权限 | 按组织规则授予所需访问，或使用管理好的公网/VPN 域名 |
| 429 | 等待一分钟，减少重复登录与刷新 |

连接操作 10 秒后超时；普通 API 请求 15 秒后超时；上传最长等待 120 秒。错误不会自动切换到演示数据来假装成功。

## 刷新或重开浏览器后需要登录

令牌在 `sessionStorage`，而服务器地址保存在 `localStorage`。重新打开浏览器可能丢失会话，这是本机状态变化；服务器账号和数据仍保留。

## 视频不播放

先确认 MP4/WebM 编码在手机浏览器支持。MP4 推荐 H.264 视频与 AAC 音频。服务端验证文件头，但不会替你转码。

签名链接一小时有效，打开页面很久后请刷新动态。代理需保留 Range 请求；出现 413 请把反向代理上传限制设置为至少 105 MB。

## 找不到发布或奖励按钮

发布需要学生账号；奖励需要老板账号。身份由注册邀请码决定。演示模式可在设置切换角色。移动端“灵感奖励”在个人主页入口可访问。

## 自动发布超时了

先登录查看是否已有相同内容，再决定是否重试。当前发布 API 不支持幂等键；上传成功但发布失败可能留下未引用媒体，不代表帖子已发布。

## 文档按钮显示 404

仅 `npm run build` 不会自动安装 Python 或构建文档。按照文档维护指南先生成 `client/public/manual`，再运行 Vite 构建。GitHub Pages 工作流已包含这一步。

## 没收到验证邮件或忘记密码

当前没有邮箱验证、邮件通知或自助密码找回，邮箱只作为登录标识。请联系实验室管理员处理账号问题，不要依赖不存在的邮件流程。
