# 版本与功能边界

## 0.1.0 · 2026-10-07

第一版面向一个大学实验室的轻量科研分享场景。

**已实现：**

- 浏览器静态客户端，手机优先布局，按服务器连接。
- 独立的本机演示、学生与老板邀请码注册、登录与退出。
- 研究手记、论文笔记和实际视频上传播放，引用、标签与搜索。
- 订阅、点赞、本人收藏、评论及作者删除。
- 8 种实验室奖励承诺，收发记录与兑现确认。
- 个人资料、受限创作者密钥与撤销。
- SQLite 持久化、签名媒体访问、Docker Compose 与可选 Caddy HTTPS。
- Markdown / Notion / 思源 ZIP 导入、可编辑分镜、Remotion 视频与发布 CLI。
- 用户手册、API 和开发文档；GitHub Pages 与 Read the Docs 构建配置。

**当前边界：**

- 单实验室、单 API 进程；不是多租户平台。
- 不代发 stipend，不处理支付，不自动购买礼品或转账。
- 没有邮件验证、密码找回、单点登录、后台管理员界面或账号删除 UI。
- 没有 Web 内置大模型服务或默认自动配音。AI 技能由创作者本地助手执行。
- 笔记使用用户主动导出的本地文件；不自动轮询 Notion/思源账号。
- 没有后台转码、媒体配额、自动垃圾回收或实时推送。
- 每条动态展示最早 100 条评论；未提供评论分页。
- 发布 API 尚无幂等键；结果未知时需人工核对再重试。
- 当前没有离线 PWA 缓存；加载网站和访问真实实验室都需要网络。

本机配置不代表云端已经部署。公开 GitHub Pages、RTD 和实验室 HTTPS 入口需由实际拥有仓库与服务器的账号完成发布。

## 2026-10-08 功能更新

新增组员身份、年级、交换身份和费用筛选；可自定义订阅计划与 7 天学生活动；压缩头像上传；个人奖励菜单；我的收入 / 我的账单；礼物使用申请、数字红点、按通知已读和兑现起止时间。离线演示扩展为 15 位虚构人物、28 条动态及私人收藏彩蛋。

新能力在演示与自托管服务器均可使用；彩蛋只用于演示。详细规则见[订阅与账本](subscriptions-and-ledger.md)。
